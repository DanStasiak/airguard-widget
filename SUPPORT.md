# Getting help

| I want to... | Go here |
| --- | --- |
| Install or update the widget | [README: Install](README.md#install-windows-1011) and [Updating](README.md#updating) |
| Fix "Not connected" or a wrong value | [README: Troubleshooting](README.md#troubleshooting) |
| Report a bug | Right-click the widget → **More → Copy diagnostics**, then [open a bug report](https://github.com/DanStasiak/airguard-widget/issues/new/choose) and paste it |
| Ask for a feature | [Feature request](https://github.com/DanStasiak/airguard-widget/issues/new/choose) |
| Use it in the browser or on a phone | [luftwaechter-ha](https://github.com/DanStasiak/luftwaechter-ha) |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md) |

Please remove personal data (addresses, tokens) from anything you post.

---

**Deutsch:** Hilfe bei Installation und Problemen steht in der [README](README.md#deutsch). Fehler bitte als Issue melden: Rechtsklick auf das Widget → **Erweitert → Diagnose kopieren** und einfügen.
